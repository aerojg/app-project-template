## 이 템플릿으로 새 앱 저장소를 만드는 방법 (새 앱에서는 이 구역을 지웁니다)

1. 이 저장소 화면의 `Use this template` → `Create a new repository`를 누릅니다.
2. 새 저장소 이름은 앱의 영문 코드명으로 정합니다(영문 소문자·숫자·하이픈).
3. 새 저장소를 PC에 복제한 뒤, 이 저장소 폴더 안에서 아래 두 줄로 커밋 이름과 가림 이메일을 설정합니다.
   - `git config --local user.name "machoman"`
   - `git config --local user.email "263141212+aerojg@users.noreply.github.com"`
4. README의 `[ ]` 부분을 앱에 맞게 고치고, 이 구역을 지웁니다.
5. 코드 파일을 만들 때는 맨 위에 아래 한 줄을 넣습니다(주석 기호는 언어에 맞게).
   - `Copyright (c) 2026 aerojg. All rights reserved. See LICENSE.`
6. 앱 화면의 "앱 정보"에도 같은 저작권 문구를 넣습니다.
7. 단계를 통과할 때마다 `docs/비밀점검표.md`와 `NOTICE.md`를 다시 점검합니다.
